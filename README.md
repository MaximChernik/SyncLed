# SyncLed

Подсветка мониторов USB-лентами ROBOBLOQ / SyncLight (VID `1A86`, PID `FE07`) и
совместимыми устройствами с протоколом RB/SC. Приложение захватывает край экрана
и отправляет цвета на каждую ленту отдельно, поэтому две ленты могут работать
каждая со своим монитором.

## Возможности

- Захват экрана через GDI, уменьшенный кадр — низкая нагрузка на CPU.
- Частота 5–60 кадров в секунду (по умолчанию 15), лишний трафик на ленту
  ограничивается автоматически.
- Отдельная привязка каждой USB-ленты к монитору.
- Раскладка светодиодов по периметру с учётом пропорций монитора.
- Сдвиг начала, реверс направления и ручное число LED по горизонтали.
- Яркость, насыщенность, гамма, сглаживание, порог чёрного, глубина краёв.
- Группы лент с общими настройками, общим режимом и цветом.
- Отдельные (свои) настройки для каждой ленты: остальные параметры наследуются
  от группы и общих настроек.
- Статичный цвет: 16 готовых оттенков, палитра Windows, цвет группы и общий
  список «Мои цвета» — сохранённый оттенок можно применить к любой ленте.
- Миниатюра в карточке: в режиме синхронизации — обводка монитора с цветами
  по периметру, для статичного цвета — полоса соответствующего цвета.
- Демонстрация настроек на миниатюре: при выключенной синхронизации короткая
  сцена показывает, как влияют яркость, насыщенность, гамма, сглаживание, порог
  чёрного, глубина краёв, сдвиг и реверс. В окне настроек ленты миниатюра своя.
- Переименование устройств и изменение их порядка перетаскиванием.
- Поканальная калибровка RGB (если лента уходит в зелёный/синий).
- Тесты «Проверить цвета» (градиент), «Бегущий огонёк» (направление) и
  «Мигнуть» (три белые вспышки, чтобы найти нужную ленту среди нескольких).
- Режимы: синхронизация с экраном, свой цвет, выключено; плюс режим
  «как в группе».
- Пресеты общих настроек: «Кино», «Игры», «Работа» и свои сохранённые наборы.
- Диагностика: частота кадров, отправленные и пропущенные кадры, трафик и
  ошибки по каждой ленте.
- Пауза при блокировке экрана, выключении монитора и уходе в сон (отключается
  флажком в общих настройках).
- Плавное затухание при остановке. Снятый флажок «Лента включена» полностью
  гасит ленту и отпускает контроллер, а не оставляет последний кадр.
- Тёмный системный заголовок всех окон, даже если Windows оформлена светлой.
- Поиск LED-устройств других производителей, совместимых с протоколом RB/SC.
- Bluetooth LE ленты на контроллерах FTY/CCHIP (сервис `0xFF01`, например
  «Light Life»): поиск по рекламе, подключение и синхронизация с экраном.
- Сворачивание в трей, горячая клавиша `Ctrl+Alt+L`, автозапуск с Windows.

## Требования

- Windows 10/11 x64.
- .NET 8 Runtime (Desktop). Если его нет — установите
  [.NET Desktop Runtime 8](https://dotnet.microsoft.com/download/dotnet/8.0).
- Официальное приложение **SyncLight должно быть закрыто**: контроллер не
  отдаётся двум программам одновременно. Если лента занята, в журнале будет
  сообщение «устройство занято другой программой».

## Сборка

Запустите `build.bat` — сначала он пересобирает `assets\app.ico` из кода
(`tools\IconGen`), затем публикует приложение в `dist\SyncLed.exe`.
Или вручную:

```
dotnet run --project tools\IconGen\IconGen.csproj -c Release
dotnet publish src\SyncLed.Desktop\SyncLed.Desktop.csproj -c Release -o dist
```

Иконку можно пересобрать отдельно: `tools\make-icon.ps1` (или с превью
`tools\make-icon.ps1 -Preview out\icons`). Знак рисуется кодом `AppIconArt`,
поэтому иконка в exe, на панели задач, в трее и в шапке окна всегда одинаковая.

Запуск: `run.bat` или `dist\SyncLed.exe`.

## Первый запуск

1. Закройте SyncLight (в том числе снимите его из автозапуска, если он
   перехватывает ленты при старте системы).
2. Запустите SyncLed. Приложение найдёт ленты (включая совместимые устройства
   других производителей, если включён их поиск) и попробует назначить
   мониторы автоматически:
   - `000503` (96 LED) — на самый большой монитор;
   - `000000` (100 LED) — на второй.
3. Проверьте привязку в карточках лент и при необходимости выберите монитор
   вручную.
4. Нажмите **Старт**.

## Калибровка

Порядок LED в лентах может отличаться от порядка зон, поэтому:

1. Нажмите **Проверить цвета** — лента покажет цветовой круг.
2. Нажмите **Бегущий огонёк** — по ленте побежит голубая точка. Посмотрите,
   откуда начинается движение и в какую сторону идёт.
3. Подберите **Сдвиг начала**, чтобы точка начиналась в левом нижнем углу
   (как у официального приложения), и включите **Реверс**, если направление
   противоположное.
4. **LED по горизонтали**: `0` — автоматический расчёт по пропорции монитора
   (для 96 LED и 16:9 это 31 сверху/снизу и 17 по бокам). Значение `24` даёт
   равные стороны по 24 LED, как в официальном SyncLight. Если цвета «съезжают»
   к углам или наоборот растянуты — подберите это число.

Кнопка **«Мигнуть»** калибровку не меняет: лента трижды вспыхивает белым — так
проще понять, какая из нескольких лент соответствует карточке.

Тест на несколько секунд приостанавливает синхронизацию, затем она
возобновляется автоматически.

## Ограничение нагрузки на контроллер

Прошивка ленты (1.7.x) не справляется с большим потоком мелких пакетов и может
зависнуть. Поэтому отправка ограничена на уровне протокола:

- кадр ужимается до **24 записей** (соседние LED с близкими цветами
  объединяются, цвет — средневзвешенный);
- суммарный трафик на ленту — около **5,5 КБ/с** (сбалансированный режим): кадр, который не влезает в
  лимит, пропускается целиком (никогда не отправляется половина пакета);
- после команд `RB` (статический цвет) выдерживается пауза 200 мс, как в
  официальном приложении;
- если картинка не меняется, кадр повторяется не чаще раза в 2 секунды.

Из-за этого значения FPS выше ~25–30 практически не повышают плавность: лишние
кадры просто не отправляются. Официальный SyncLight шлёт около 10 кадров в
секунду.

## Настройки и наследование

Конфигурация хранится в `config.json` рядом с `SyncLed.exe` (если папка
недоступна для записи — в `%APPDATA%\SyncLed\config.json`). Файл можно
редактировать вручную, но проще через интерфейс.

Параметры (яркость, насыщенность, гамма, сглаживание, порог чёрного, глубина
краёв) берутся по цепочке:

1. собственные настройки ленты, если в диалоге **«Настройки…»** включён флажок
   «Отдельные настройки для этой ленты»;
2. настройки группы, если у неё включён флажок «Свои настройки группы»;
3. общие настройки приложения.

Режим и статичный цвет наследуются так же: «как в группе» → режим группы →
синхронизация; пустой цвет ленты → цвет группы → белый.

К статичному цвету перед отправкой применяются те же яркость, насыщенность,
гамма и баланс RGB, что и при синхронизации, поэтому лента не выглядит бледнее
выбранного оттенка.

Сдвиг, реверс, ручное число LED по горизонтали и баланс RGB всегда задаются
отдельно для каждой ленты.

## Bluetooth-ленты (FTY/CCHIP)

Ленты на контроллерах CCHIP (например, «Light Life», сервис `0xFF01`,
характеристики `0xFF03` для записи и `0xFF02` для уведомлений) находятся
автоматически, если включён флажок **«Искать Bluetooth-ленты»**. Найденная лента
добавляется в список как обычная и управляется тем же движком.

Протокол: пакет `A0 <команда> <длина+3> <данные…> <CRC16 lo> <CRC16 hi>`,
CRC-16 Modbus (полином `0xA001`, начальное значение `0xFFFF`). Перед командами
выполняется рукопожатие `CCHIP`. Команды: `0x11` — включить/выключить,
`0x12` — режим, `0x13` — яркость (0…100), `0x15` — цвет `R G B 0xFF`.

Неадресуемая лента (4 пина: `+5V`/`12V`, `R`, `G`, `B`) получает один цвет:
цвета всех зон смешиваются с весом по яркости.

**Важно про яркость.** У дешёвых контроллеров при яркости выше ~30 срабатывает
защита по току: лента вспыхивает и гаснет через секунду (то же самое происходит
и в официальном приложении). Поэтому у каждой Bluetooth-ленты в карточке есть
ползунок **«Яркость контроллера»** — аппаратная яркость именно этой ленты
(1…100). Значение из общих настроек **«Яркость Bluetooth-лент (общая)»**
используется как значение по умолчанию для лент, у которых своя яркость ещё не
задана. Если лента гаснет на светлых участках — уменьшите значение; если после
замены блока питания всё стабильно — можно поднять до 100.

Bluetooth-контроллер держит только одно подключение: перед запуском SyncLed
закройте официальное приложение, а если лента не находится — передёрните её
питание.

SyncLed периодически спрашивает состояние контроллера и, если лента погасла
из-за защиты по току, повторно включает её (с нарастающей паузой, чтобы не
мигать). Это страховка: стабильно работать лента должна на безопасной яркости.

## Группы

Кнопка **«Группы…»** в верхней панели открывает редактор групп:

- участники группы перечислены в списке «Ленты в группе»;
- группа может задавать свои параметры, режим и цвет;
- флажок **«Делить периметр монитора между лентами группы»** заставляет ленты
  одной группы на одном мониторе работать как одна длинная лента: периметр
  делится между ними пропорционально числу LED, без дублирования картинки.

Ленту можно добавить в группу и из её карточки (поле «Группа»). Если лента была
в режиме «Синхронизация», при добавлении в группу она переключается на «Как в
группе», а при удалении из группы — обратно на «Синхронизация».

## Палитра

Строка «Цвет» в карточке ленты содержит 16 готовых оттенков, кнопку
**«Свой…»** для выбора произвольного цвета и кнопку **«из группы»**, которая
очищает собственный цвет ленты. Клик по любому образцу включает режим
«Свой цвет».

## Карточки устройств

Каждая лента показана отдельной карточкой. Над настройками расположена
миниатюра:

- **Синхронизация с экраном** — обводка монитора: цвета бегут по периметру так
  же, как на реальной ленте; внутри экрана видно мягкое свечение текущих цветов.
  Если синхронизация ещё не запущена, обводка серая и написано «нет данных».
- **Свой цвет** — светящаяся полоса выбранного оттенка; на ленту он уходит
  с поправкой на яркость, насыщенность, гамму и баланс RGB.
- **Выключено** — тёмная полоса с подписью «выключено».

Заголовок карточки можно изменить: двойной щелчок по названию или кнопка с
карандашом. Новое имя сохраняется в `config.json` (поле `Name`) и используется
в журнале, списке групп и подсказках.

Порядок карточек сохраняется в `config.json` и восстанавливается при запуске.
Перетащите карточку за значок `⠿` слева от названия (или за сам заголовок) —
синяя линия покажет место вставки. Порядок сразу сохраняется в конфиг.

## Другие производители

Флажок **«Искать LED-устройства других производителей»** в общих настройках
включает расширенный поиск. Кроме известного `1A86:FE07` приложение проверяет
vendor-defined HID-устройства с 64-байтными отчётами: если контроллер отвечает
на запрос параметров RB/SC, он добавляется как лента. Поиск ограничен по
времени и числу проверяемых устройств, чтобы не задерживать запуск. Отключите
флажок, если в системе есть другие HID-устройства и поиск мешает.

## Автозапуск

Флажок **«Запускать вместе с Windows»** создаёт запись `SyncLed` в
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` с ключом `--minimized`.
Приложение стартует свёрнутым в трей и сразу включает синхронизацию, если
включён флажок «Запускать синхронизацию при запуске».

## Горячие клавиши

- `Ctrl+Alt+L` — включить/выключить синхронизацию.

## Пресеты

Секция **«Пресеты»** в начале страницы «Настройки» содержит список наборов.
Пресет хранит только базовые параметры: яркость, насыщенность, гамму,
сглаживание, порог чёрного и глубину краёв.

- **Применить** — переносит значения пресета в общие настройки. Собственные
  настройки лент и групп при этом не меняются: они, как и раньше, перекрывают
  общие значения.
- **Сохранить текущие** — записывает текущие общие настройки под именем из поля
  «Название нового пресета». Одноимённый пресет перезаписывается.
- **Удалить** — убирает выбранный пресет.

Строка **«Активный пресет»** показывает, какой набор действует сейчас:

- зелёное «Активен: «Кино»» — текущие общие настройки полностью совпадают
  с пресетом, в списке он отмечен галочкой и подписью «активен»;
- жёлтое ««Кино» · настройки изменены» — пресет применялся, но слайдеры уже
  сдвинуты;
- серое «Свои настройки — пресет не задан» — значения не совпадают ни с одним
  набором и активный пресет не запоминался.

Имя активного пресета хранится в `config.json` (поле `ActivePresetName`) и
восстанавливается при следующем запуске.

По умолчанию есть три набора: «Кино», «Игры» и «Работа». Список хранится в
`config.json` (поле `Presets`).

## Диагностика

Кнопка **«Диагностика»** в верхней панели показывает, что происходит с движком
и каждой лентой:

- частота кадров, время кадра и общее число кадров;
- транспорт (USB/BLE), состояние, монитор и режим каждой ленты;
- отправленные и пропущенные кадры, трафик в секунду и ошибки;
- **«Копировать отчёт»** — весь снимок текстом в буфер обмена.

«Пропущено» — это кадры, которые не влезли в лимит трафика контроллера (см.
раздел об ограничении нагрузки); для USB при высокой частоте это нормально.
Счётчики накопительные с момента запуска приложения, окно обновляется раз в
секунду и только пока открыто.

## Пауза и выключение

При блокировке экрана, выключении монитора или уходе системы в сон
синхронизация приостанавливается и ленты гаснут; после разблокировки включается
снова. Отключить это поведение можно флажком **«Пауза при блокировке и сне»** в
общих настройках.

Кнопка **«Стоп»** не обрывает картинку: последние цвета плавно затухают за
несколько кадров, после чего ленты выключаются. Флажок **«Лента включена»** в
карточке — это полное выключение: лента гаснет, контроллер закрывается, а
миниатюра становится тёмной. При повторном включении лента открывается заново.

## Протокол (для справки)

HID output report — 65 байт (report id 0 + 64 байта данных), пакет режется на
чанки по 64 байта.

- Статический цвет: `'R','B', len=6+5k, msgId, 134, [start,r,g,b,end]*k, checksum`.
- Синхронизация: `'S','C', uint16BE len, msgId, 128, [start,r,g,b,end]*k, checksum`.
- Чтение параметров: `'R','B',6,msgId,130,checksum` — ответ содержит productId,
  количество LED, UUID и версию прошивки.
- При подключении отправляется `setOpenUrl(0)` (action 147).

| Ленты не найдены | Переподключить USB, проверить диспетчер устройств (HID-устройство ROBOBLOQ). Для других производителей включить поиск совместимых устройств. |
| Лента «зависла» (не меняет цвет, ошибок нет) | Отключить и снова подключить USB-кабель ленты — питание контроллера сбрасывается только так. |
| Цвета есть, но не совпадают с краями | Настроить «Глубину краёв», «Сдвиг», «LED по горизонтали». |
| Лента мигает/дёргается | Снизить FPS до 10–15, увеличить сглаживание. |
| Перепутаны мониторы | Поменять монитор в карточке ленты. |
| Слишком тёмная картинка | Увеличить яркость/гамму, уменьшить порог чёрного. |
